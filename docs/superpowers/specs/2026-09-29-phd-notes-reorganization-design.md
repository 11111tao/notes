# 博士阶段公开笔记站重组设计

## 目标与边界

将现有 Material for MkDocs 站点整理为从博零到毕业持续使用的公开学习笔记。访客能够按用途找到课程、文献、通用知识和工具笔记；作者能够按时间回顾博士阶段的计划与成长。

站点只收录可公开内容。未发表课题的构想、实验、数据、结论、组会细节和合作信息保存在另一个 Obsidian Vault，不进入本仓库。`docs/` 仍是公开站点的 Obsidian Vault。发布前应把任何新页面视为公开材料审阅；仅从 MkDocs 导航或构建中排除文件不能保护公开 Git 仓库里的源文件。

## 信息架构

首页提供五个一级入口：

| 入口 | 内容范围 | 首次落地 |
| --- | --- | --- |
| PhD Journey | 学期计划、月度回顾、阶段总结；研究只写可公开的个人学习与成长 | 建立入口与写作范围说明 |
| Courses | 按课程整理概念、推导、习题与难点 | 建立入口及「化工数学」课程页，不编造课程笔记正文 |
| Papers | 已公开论文的阅读笔记，每篇论文一个页面 | 迁入现有 Bai Lab 论文阅读内容，保留原文、引用与图片 |
| Concepts | 可反复查阅的知识和方法，按主题逐步细分 | 迁入 CNN、智能体机制、递归自我改进笔记 |
| Tools | 软件、编程环境和研究工作流的实际使用记录 | 建立入口与范围说明 |

不设公开的 Research 一级板块。未来确有已公开的个人研究成果时，再增设相应入口。博士年份和月份用于 PhD Journey 的时间线，不作为全部笔记的顶层分类。

## 内容迁移

- 移除 `docs/TDP Dataset/`、`docs/Physical Intelligence/`、`docs/Crypto/` 的公开页面和无其他引用的专属附件。
- 移除 `docs/Bai Lab/meeting-0920.md` 和旧 Bai Lab 入口。用户明确同意删除现有组会记录，包括其未提交修改。
- 将 `docs/Bai Lab/mission-001-read-articles.md` 中关于已公开论文的阅读内容迁入 Papers。该文件有未提交修改；迁移时保留正文，不把组会信息带入 Papers。拆分论文页面时保留现有引用和图片链接。`tdp-workflow.png` 被该论文笔记引用，不能因删除 TDP 页面而一并删除。
- 将现有 AI 三篇笔记迁入 Concepts 的恰当子主题，修复随路径变化的相对图片链接。移除旧 AI 入口。
- 更新首页与 README，让新建笔记和发布流程遵循公开边界；同步更新内容完整性测试中的预期页面与一级入口。
- 不改写历史设计文档；它们位于 MkDocs 的 `exclude_docs` 范围内，作为当时的项目记录保留。

## 首页图标问题

当前首页使用 `:material-brain:` 等图标短代码，但 `mkdocs.yml` 没有启用 `pymdownx.emoji`，因此短代码被当作普通文字显示。这是构建配置问题，不是 Chrome 渲染故障。按 Material for MkDocs 的官方配置添加 `pymdownx.emoji`，使用 `material.extensions.emoji.twemoji` 和 `material.extensions.emoji.to_svg`，使图标在生成的 HTML 中成为 SVG。

## 验证与发布

1. 执行 `mkdocs build --strict` 和内容完整性测试。
2. 检查生成首页的图标 SVG、五个入口与所有本地链接；确认迁移后的论文图片存在。
3. 确认被移除板块和组会页面不再出现在生成站点。
4. 查看 Git 差异，确保现有未提交的论文笔记修改得到保留，未发表研究内容没有新增到公开站。

本设计只要求完成本地整理与验证。是否提交内容、推送及发布按后续具体指令决定。删除页面不会清除公开仓库的 Git 历史或外部副本；若发现旧内容确属机密披露，历史清理需单独评估。
